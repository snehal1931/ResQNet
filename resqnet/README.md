# 🚨 ResQNet

### AI-Powered Disaster Prediction & Emergency Response System

---

## 📌 Overview

**ResQNet** is an intelligent disaster management system designed to **predict risks, analyze situations, and assist in emergency response** using AI and real-time data processing.

The goal of this project is to **minimize damage, improve response time, and help authorities make faster decisions during critical situations**.

---

## ❗ Problem Statement

Natural disasters like floods, earthquakes, and fires cause:

* Delayed response
* Lack of real-time coordination
* Poor risk assessment

There is a need for a **smart system** that can:

* Predict disaster risks
* Alert users in advance
* Assist in rescue planning

---

## 💡 Solution

ResQNet provides:

* 🤖 AI-based risk prediction
* 📊 Data-driven analysis
* 📡 Real-time communication support
* 🧭 Smart decision assistance

---

## ✨ Features

* 🚨 Disaster risk prediction using AI models
* 📍 Location-based analysis
* 💬 Communication system (chat/message support)
* 🗺️ Mesh network simulation for connectivity
* 📊 Admin dashboard for monitoring
* ⚡ Fast and responsive system

## ⚙️ Installation & Setup

### 🔹 Clone the repository

```bash
git clone https://github.com/snehal1931/ResQNet.git
cd ResQNet
```

---

### 🔹 Backend Setup

```bash
cd backend
pip install -r requirements.txt
python model_trainer.py
```

---

### 🔹 Frontend Setup

```bash
cd resqnet
flutter pub get
flutter run
```
